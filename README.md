## Proyek software

- **[LampirGen](https://github.com/rivanfathur-rgb/lampir)**: aplikasi web untuk menyusun foto lampiran laporan praktikum ke Word secara otomatis. [Coba langsung](https://lampiran-rivan.streamlit.app/)
- **[Armwrestling Tracker](https://github.com/rivanfathur-rgb/armwrestling-tracker)**: aplikasi mobile untuk mencatat latihan armwrestling (jadwal, set, riwayat, dan progres). Masih dalam pengembangan.

## Proyek elektronika

- **[ESP32 BLE Joystick Mouse](https://github.com/rivanfathur-rgb/esp32-ble-joystick-mouse)**: mouse Bluetooth (BLE) buatan sendiri dengan ESP32 dan joystick analog KY-023, lengkap dengan diagram wiring dan panduan penggunaan.

Proyek lain berikut ini dokumentasinya (foto, video, skema, dan kode) sedang disiapkan dan akan ditambahkan bertahap:

- Jam digital seven segment (menit:detik): desain skematik sampai layout PCB di KiCad (belum dicetak)
- PCB LED berbentuk hati di EasyEDA (belum dicetak)
- Kontrol pola LED lewat web lokal dengan ESP32
- Servo pan-tilt berlaser, dikendalikan lewat HP lalu diganti dengan joystick
- Memory game LED: urutan warna acak, level bertambah, dan game over jika salah
